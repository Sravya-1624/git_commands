| No. | Command              | When should I use it?                                                      | Syntax / Example                              |
| --: | -------------------- | -------------------------------------------------------------------------- | --------------------------------------------- |
|   1 | **`docker pull`**    | When you want to download an image from Docker Hub.                        | `docker pull ubuntu`                          |
|   2 | **`docker images`**  | When you want to see locally available Docker images.                      | `docker images`                               |
|   3 | **`docker build`**   | When you have a Dockerfile and want to create an image.                    | `docker build -t ai-olms:latest .`            |
|   4 | **`docker run`**     | When you want to create and start a container from an image.               | `docker run ai-olms:latest`                   |
|   5 | **`docker run -d`**  | When you want the container to run in the background.                      | `docker run -d ai-olms:latest`                |
|   6 | **`docker run -it`** | When you want an interactive terminal inside a container, commonly Ubuntu. | `docker run -it ubuntu`                       |
|   7 | **`--name`**         | When you want to give the container a meaningful name.                     | `docker run -d --name myapp image`            |
|   8 | **`-p`**             | When you want to map a host port to a container port.                      | `-p 8080:8080`                                |
|   9 | **`docker ps`**      | When you want to see currently running containers.                         | `docker ps`                                   |
|  10 | **`docker ps -a`**   | When you want to see running + stopped containers.                         | `docker ps -a`                                |
|  11 | **`docker logs`**    | When you want to see application/container output or troubleshoot crashes. | `docker logs mycontainer`                     |
|  12 | **`docker exec`**    | When you want to execute a command inside a running container.             | `docker exec -it mycontainer bash`            |
|  13 | **`docker inspect`** | When you need detailed information about a container.                      | `docker inspect mycontainer`                  |
|  14 | **`docker stop`**    | When you want to stop a running container.                                 | `docker stop mycontainer`                     |
|  15 | **`docker rm`**      | When you want to delete a container.                                       | `docker rm mycontainer`                       |
|  16 | **`docker cp`**      | When you want to copy a file from your computer into a container.          | `docker cp target/app.war mycontainer:/path/` |
|  17 | **`docker tag`**     | When you want to give an image a Docker Hub repository name/tag.           | `docker tag app:latest user/app:latest`       |
|  18 | **`docker login`**   | Before pushing images to Docker Hub.                                       | `docker login`                                |
|  19 | **`docker push`**    | When you want to upload an image to Docker Hub.                            | `docker push user/app:latest`                 |

| Git                          | Docker                                       |
| ---------------------------- | -------------------------------------------- |
| `git clone`                  | `docker pull`                                |
| Downloads a **repository**   | Downloads an **image**                       |
| `git status`                 | `docker ps`                                  |
| Checks Git files/status      | Checks running containers                    |
| `git commit`                 | `docker build`                               |
| Saves changes in Git history | Creates an image                             |
| `git push`                   | `docker push`                                |
| Sends code commits to GitHub | Sends Docker image to Docker Hub             |
| `git pull`                   | `docker pull`                                |
| Gets GitHub changes          | Gets Docker image                            |
| `git branch`                 | No equivalent needed for these lab questions |
| `git merge`                  | No equivalent needed                         |
| `git revert`                 | No equivalent needed                         |
