Useful ways to access the app
minikube service demo-app
kubectl port-forward service/demo-app 8081:80
The first command opens the Service through Minikube. The second forwards your computer's port 8081 to Service port
80. Keep the port-forward terminal open while testing.
Self-healing demonstration
kubectl get pods
kubectl delete pod POD_NAME
kubectl get pods -w
Delete one Pod from the Deployment and watch Kubernetes create a replacement. Use the exact Pod name shown by
kubectl get pods. Explain that the Deployment's desired replica count is maintained by its ReplicaSet.
Rolling update and rollback
kubectl set image deployment/demo-app nginx=nginx:1.25
kubectl rollout status deployment/demo-app
kubectl rollout history deployment/demo-app
kubectl rollout undo deployment/demo-app
kubectl get pods
The container name in the image-update command must match the container name inside the Deployment. For an Nginx
deployment created by kubectl, it is normally nginx.
Kubernetes troubleshooting
kubectl get pods
kubectl describe pod POD_NAME
kubectl logs POD_NAME
kubectl logs POD_NAME --previous
kubectl get events --sort-by=.metadata.creationTimestamp
kubectl get deployments
kubectl get services
• Pending: Pod could not be scheduled; inspect Events, resource requests and node availability.
• ImagePullBackOff: Check image name, tag, registry access and spelling.
• CrashLoopBackOff: Container repeatedly exits; inspect logs and configuration.
• Service not reachable: Check Service selector, Pod labels, targetPort, Pod readiness and NodePort access.
• Wrong replica count: Check Deployment and run kubectl scale again.
Cleanup
kubectl delete service demo-app
kubectl delete deployment demo-app
minikube stop
Part B: Nagios fundamentals
What is Nagios? Nagios is an IT infrastructure monitoring tool. It checks hosts and services and reports states such as
OK, WARNING, CRITICAL and UNKNOWN. It can notify administrators when configured checks detect problems.
Host vs service: A host is the machine/device being monitored. A service is a particular check on that host, such as
HTTP, SSH, disk usage or a database port.

This is a teaching template. The web service above must be a real backend configured to connect to PostgreSQL at host
db, port 5432, and Redis at host redis, port 6379. A static Nginx page alone does not use either database service. Change
sample passwords before real use.
